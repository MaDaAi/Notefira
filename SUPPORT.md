# Getting help with Notefira

Notefira's support happens on GitHub, in public, so answers can help everyone. Pick the place that matches what you need:

| I want to… | Go to |
|---|---|
| Ask a question, get help or troubleshoot | [Discussions → Q&A](https://github.com/MaDaAi/Notefira/discussions/categories/q-a) |
| Suggest an idea or talk about the project | [Discussions](https://github.com/MaDaAi/Notefira/discussions) |
| Report a bug or request a specific feature | [Issues](https://github.com/MaDaAi/Notefira/issues/new/choose) |
| Contribute code or documentation | [CONTRIBUTING.md](CONTRIBUTING.md) |
| Report a security vulnerability (privately) | [SECURITY.md](SECURITY.md) |
| Ask a privacy or legal question privately | Email **notefirasupport@gmail.com** |

## Before you ask

- Search existing [discussions](https://github.com/MaDaAi/Notefira/discussions) and [issues](https://github.com/MaDaAi/Notefira/issues) — your question may already be answered.
- Mention where you use Notefira (browser and device, or desktop app and operating system).
- For problems, you can attach a diagnostic log from **Help → Export diagnostic log** — read it first and remove anything private.

## Please keep private things private

GitHub issues and discussions are public. Don't post your notebooks, personal notes, email addresses or other personal information. Notefira's maintainers will never ask for your Google password or sign-in codes.

## Your data

Notefira stores your notebooks on your own device, so the maintainers can't see, recover or restore them. Keep regular backups with **Settings → Backup & storage**.

Support is provided by volunteers on a best-effort basis.
